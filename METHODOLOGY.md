# Methodology

## SQL Phase

I built this analysis in two phases. First, I used SQL to pull financial data from the WRDS Compustat database covering five major US telecoms from 2020 through 2025. I wrote 16 queries to calculate the key metrics that matter for understanding debt health: leverage ratios like debt-to-equity and debt-to-EBITDA, solvency metrics like interest coverage and debt service capacity, and balance sheet composition to see how companies fund themselves. Each query transformed raw financial data into actionable business metrics, and I exported the results as CSV files.

## Tableau Phase

Then I moved to Tableau to visualize what the numbers actually mean. I built seven interactive dashboards showing how these metrics evolved over time, how companies compare to each other, and where the real risks lie. I added industry benchmarks to each dashboard so you can see at a glance who's operating normally versus who's stretching their leverage. The visualizations reveal patterns that raw numbers often hide—like how Charter's debt isn't just high, it's getting more expensive to refinance (in comparison with 2020), or how Comcast Corporation has quietly become the safest investment in the group.
